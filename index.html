    How This Agent Works

    This prototype demonstrates the core loop of an intelligent software agent using only frontend code, rule-based logic, and browser memory.

    Perception

    The agent reads your study goal, deadline, difficulty level, and available hours per day from the form.

    Decision-making

    Rule-based logic assigns a priority level, breaks the goal into tasks, estimates total study time, and generates a recommendation.

    Action

    The agent displays your plan, tracks task completion, updates progress, and lets you reset when needed.

    Memory

    Your plan and progress are saved in localStorage so they persist after you refresh the page.
